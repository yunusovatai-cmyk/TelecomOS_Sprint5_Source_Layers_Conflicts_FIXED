# Sprint 0 Acceptance Criteria

Sprint 0 считается завершённым, если:

1. `docker compose up --build` запускает все сервисы.
2. Frontend открывается на порту 3000.
3. Swagger открывается на порту 8000.
4. `/health` подтверждает подключение к PostgreSQL.
5. Project можно создать из UI.
6. Project сохраняется в PostgreSQL.
7. MinIO Console доступна.
8. Redis отвечает на health check.
9. CI проверяет backend и frontend.
